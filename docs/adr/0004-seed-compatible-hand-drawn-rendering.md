# Seed-compatible port of rough.js and perfect-freehand

Shapes are generated by an idiomatic (not line-by-line) port of rough.js and perfect-freehand that reproduces the same strokes for the same Element `seed`, so a Drawing looks identical here and on excalidraw.com. A simpler home-grown sketchy renderer was rejected because files would visibly change when moved between apps. Fidelity is guarded by golden tests against the JS libraries' output.
