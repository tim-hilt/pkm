# Notes

The Context for written Markdown texts, kept in Folders. App-wide terms (Context, Item, Item ID, Delete, Device, Cloud Backing, Sync) are in the [App glossary](../../GLOSSARY.md); Inline formatting is the [Tasks glossary](../tasks/GLOSSARY.md)'s.

## Language

**Note**:
One written Markdown text, with a Title and a Body. A Note left with both empty is no Note.
_Avoid_: Page, document, item (when meaning a Note specifically)

**Title**:
The one line naming a Note; may be empty, and lists then show the Body's first line instead. Takes Inline formatting only, as a Task's Title.
_Avoid_: Name, heading, file name

**Body**:
The Markdown text of a Note, everything but its Title: headings, Inline formatting, lists, links, Images, code blocks and quotes.
_Avoid_: Description (that is a Task's), content, text

**Image**:
A picture pasted into a Body, kept in its Note's Folder, moved and Deleted with it, or Deleted once no Body shows it any more.
_Avoid_: Attachment, picture, file

### Folders

**Folder**:
A named place holding Notes and other Folders, at any depth; it shows its Folders by name, then its Notes newest-changed first. A Note is in one Folder or at the **top level**. Two Folders in one place never share a name, whatever the case.
_Avoid_: Notebook, directory, collection, Tag

**Move**:
Putting a Note or Folder into another Folder or the top level; a Note keeps its Item ID, its Images go with it.
_Avoid_: Rename (for a Note), file, sort

**Delete a Folder**:
Deleting a Folder with every Note, Image and Folder in it, on every Device. A Note Moved into it elsewhere at the same time lands at the top level instead.
_Avoid_: Remove, empty

### Search

**Search**:
Finding Notes in any Folder by words in their Title or Body, ignoring case and accents; Title matches first.
_Avoid_: Filter (that is Tasks'), find, lookup, Library Search (that is Books')
