# Notes

The Context for written Markdown texts, organised by Tags only, never in folders. App-wide terms (Context, Item, Item ID, Delete, Tag, Device, Cloud Backing, Sync) are in the [App glossary](../../GLOSSARY.md); Inline formatting is the [Tasks glossary](../tasks/GLOSSARY.md)'s.

## Language

**Note**:
One written Markdown text, with a Title, a Body and Tags. A Note left with both empty is no Note.
_Avoid_: Page, document, item (when meaning a Note specifically)

**Title**:
The one line naming a Note; may be empty, and lists then show the Body's first line instead. Takes Inline formatting only, as a Task's Title.
_Avoid_: Name, heading, file name

**Body**:
The Markdown text of a Note, everything but its Title: headings, Inline formatting, lists, links, Images, code blocks and quotes.
_Avoid_: Description (that is a Task's), content, text

**Image**:
A picture pasted into a Body, kept beside its Note and Deleted with it, or once no Body shows it any more.
_Avoid_: Attachment, picture, file

### Search

**Search**:
Finding Notes by words in their Title or Body, ignoring case and accents; Title matches first.
_Avoid_: Filter (that is Tasks'), find, lookup, Library Search (that is Books')
